# Nashmi Android — Reverse TCP Tunnel MVP

المستودع يحتوي تطبيقين Android مستقلين:
- `NashmiServer`: هاتف مركزي يستقبل اتصال العميل وينشر منفذاً TCP لكل جهاز.
- `NashmiClient`: يتصل بالخادم اتصالاً صادراً ثم يمرر الاتصالات الواردة إلى خدمة محلية على جهاز العميل.

## الحالة
المصدر الأولي للتطبيقين وإعدادات Gradle وملف GitHub Actions موجودة. البناء التلقائي ينتج Debug APKs كـ Actions Artifacts عند push إلى `main` أو التشغيل اليدوي من Actions.

## حدود مهمة
هذا نموذج MVP/PoC وليس خدمة جاهزة للإنتاج. البروتوكول الحالي يستخدم TCP خاماً وtoken مشتركاً دون TLS، ولا يطبق HTTP reverse proxy أو إدارة شهادات. لا تفتح منافذ 7000 أو 7001 أو منافذ الخدمات للإنترنت العام، ولا تمرر بيانات حساسة. يلزم TLS موثق ومفاتيح منفصلة لكل جهاز وإلغاء اعتماد واختبارات أمنية وضغط قبل النشر.
