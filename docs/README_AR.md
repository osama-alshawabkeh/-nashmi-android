# Nashmi APK v1 — مصدر أولي لتطبيقين Android

## الملفات
- `NashmiServer/`: مشروع Android Studio لتطبيق الخادم.
- `NashmiClient/`: مشروع Android Studio لتطبيق العميل.

## الوظائف الحالية
- واجهة إعداد Server وClient.
- Foreground Service مع إشعار دائم.
- تشغيل تلقائي بعد الإقلاع عند توفر إعداد محفوظ، وفق قيود Android.
- بروتوكول Reverse TCP بسيط: العميل يبدأ اتصال التحكم الصادر إلى الخادم، والخادم يطلب من العميل فتح قناة بيانات صادرة لكل اتصال وارد.
- كل جهاز يحدد منفذ TCP عام منفصلاً ضمن 18000-18999.
- لا يحتاج جهاز العميل إلى IP ثابت أو Port Forwarding في راوتره.

## بناء APK
افتح كل مجلد على حدة في Android Studio حديث يدعم AGP 8.10.1 وKotlin 2.1.20، ثم Build > Build Bundle(s) / APK(s) > Build APK(s). المسار المعتاد: `app/build/outputs/apk/debug/app-debug.apk`.

لم يتم إنتاج APK أو اختبار البناء على TECNO Android 16 في هذه الحزمة. هذه مصدر يحتاج بناء واختبار.

## إعداد الشبكة
على راوتر هاتف الخادم فقط، حوّل TCP 7000 و7001 إلى هاتف الخادم، وكذلك منفذ العميل العام المختار (مثلاً 18001).

## تحذير أمني
هذا إصدار PoC يستخدم TCP خاماً وToken مشتركاً دون TLS أو شهادات أو تدوير مفاتيح. لا تفتح المنافذ للعامة ولا تمرر بيانات حساسة قبل إضافة TLS موثّق، إدارة أسرار آمنة، تحديد معدل الطلبات، عزل الأجهزة، واختبارات أمنية.

## قيود
- لا يوجد ضمان لعدد غير محدود من الأجهزة؛ RAM والمعالج والإنترنت والحرارة تحد السعة.
- الإصدار يدعم TCP forwarding فقط؛ لا توجد طبقة Reverse Proxy ذكية أو إدارة شهادات/مضيفين.
- التشغيل التلقائي قد يتأثر بقيود Android 16 وإدارة البطارية في TECNO.
- لا توجد حالياً واجهة إدارية لإزالة تسجيلات العملاء القديمة.
